# Ahmed Hassan Sayed — Portfolio

A frontend-only React + Vite dashboard-style personal portfolio.

## Run locally

```bash
npm install
npm run dev
```

Then open the printed local URL (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Tech stack
- React 18 + Vite
- React Router (client-side routing only, no backend)
- lucide-react icons
- Hand-built SVG charts (line, donut, bar) — no charting library
- Plain CSS3 (custom properties for light/dark theme)

## Notes
- No backend, no database, no authentication.
- The contact form is a frontend-only demo: submitting shows a local success toast,
  or use "Open in Mail App" to launch a real `mailto:` draft.
- Theme preference is saved to `localStorage`.
- Press `Ctrl+K` (or `Cmd+K` on Mac) anywhere to open the command palette.
- Keyboard shortcuts: `H` Dashboard, `P` Projects, `S` Skills, `C` Contact.
